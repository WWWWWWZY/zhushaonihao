# 🎭 整蛊小程序

两个有趣的整蛊网页，适合发给朋友开玩笑~

## 📱 使用方法

直接把链接发给朋友，让TA用手机打开即可！

### 🐷 画猪游戏 (pig.html)
- 自动一个个点画出小猪佩奇
- 最后显示"迎接猪少"
- 有猪叫声效果
- 画完之前无法关闭页面

### 💣 疯狂弹窗 (popup.html)
- 不断弹出"你是傻子"窗口
- 关一个弹两个
- 最多20个窗口
- 必须全部关完才能结束

## ⚠️ 注意事项

- 仅供娱乐，请勿用于恶意目的
- 玩得开心，但别玩过火
- 整蛊完记得告诉对方这只是个玩笑
